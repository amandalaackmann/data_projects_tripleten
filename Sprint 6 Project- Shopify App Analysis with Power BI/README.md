# Sprint 6 – Shopify App Analysis (Power BI)

## 📌 Objective
Analyze Shopify apps to understand review patterns and developer responsiveness.

## 🛠 Tools & Skills Used
- Power BI (data modeling, DAX)
- Excel (`shopify.xlsx`)

## 📊 Key Steps
1. Modeled tables (`apps`, `reviews`, `categories`, `apps_categories`).
2. Created KPIs, line/scatter charts; DAX columns `helpful_reviews` and `developer_answered`.
3. Built pages for App Landscape, Reviews, and Developer insights.

## 📈 Results / Insights
- Most responsive developers tend to have higher average ratings.
- Categories with high engagement but lower ratings identified for improvement.

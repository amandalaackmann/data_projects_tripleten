# Sprint 2 – Exploring Startup Trends with SQL

## 📌 Objective
Investigate startup investment patterns by querying a relational database to uncover funding trends, top-performing industries, and investor activity.

## 🛠 Tools & Skills Used
- SQL (PostgreSQL)  
- Aggregate functions (`SUM`, `AVG`, `COUNT`)  
- Grouping and filtering (`GROUP BY`, `HAVING`)  
- Multi-table joins (`INNER JOIN`, `LEFT JOIN`)  
- Sorting and limiting results  

## 📊 Key Steps
1. Connected to the startup funding dataset (companies, funding rounds, investors).  
2. Retrieved subsets using `SELECT` and `WHERE`.  
3. Summarized funding using aggregate functions.  
4. Grouped and filtered by industry, location, and funding type.  
5. Joined tables for a unified view of trends.  
6. Ordered and limited results to highlight top performers.  

## 📈 Results / Insights
- Identified industries receiving the highest total funding.  
- Pinpointed top investors by deals and capital deployed.  
- Highlighted locations with the most startup activity.  
- Provided insights for focusing investment on emerging industries.

# Sprint 3 – Business & User Performance Analysis

## 📌 Objective
Analyze conversion funnel performance and retention cohorts to understand drop-off points and long-term engagement.

## 🛠 Tools & Skills Used
- Excel (pivot tables, calculated fields)  
- Conversion funnel analysis  
- Cohort retention analysis  

## 📊 Key Steps
1. Imported event logs (`user_id`, `event_type`, `event_date`).  
2. Classified events: view, cart, purchase.  
3. Built conversion funnel (view → cart → purchase).  
4. Created cohorts grouped by first purchase month.  
5. Measured retention over four months.  
6. Summarized key drop-offs and patterns.  

## 📈 Results / Insights
- View → Cart conversion: **29%**.  
- View → Purchase conversion: **10%**.  
- Retention dropped from **6% in month 1** to **3% by month 4**.  
- Clear need for checkout optimization and re-engagement campaigns.

# Sprint 4 – Superstore Data Visualization

## 📌 Objective
Identify profit centers, loss drivers, and patterns using Tableau visuals built from the Superstore dataset.

## 🛠 Tools & Skills Used
- Tableau (calculated fields, dashboards)
- Excel (`Superstore.xls` as source)

## 📊 Key Steps
1. Connected to Superstore data and prepared fields.
2. Built visuals to analyze profit by category/subcategory and trends.
3. Assembled an interactive dashboard and published to Tableau Public.

## 📈 Results / Insights
- Clear top/bottom subcategories by profit.
- Visualized profit trends and distribution across products.

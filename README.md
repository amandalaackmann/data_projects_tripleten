# TripleTen Business Intelligence Projects

This repository contains all of my projects from the **TripleTen Business Intelligence Bootcamp** (Sprints 1–7 + Final Project). Each project simulates real-world business intelligence workflows, using Excel, SQL, Tableau, and Power BI to deliver actionable insights.  

## 📂 Project Portfolio

| Sprint | Project Title | Description |
| :----: | ------------- | ----------- |
| 1 | [Excel Data Cleaning & Pivot Analysis](Sprint_1_Excel_Project/README.md) | Applied data cleaning and preprocessing techniques in Excel; created pivot tables to summarize and interpret data for business reporting. |
| 2 | [Exploring Startup Trends with SQL](Sprint_2_SQL_Project/README.md) | Wrote advanced SQL queries using aggregate functions, grouping, filtering, and multi-table joins to extract actionable insights from relational databases. |
| 3 | [Business & User Performance Analysis](Sprint_3_Business_Analytics/README.md) | Analyzed key business and user performance metrics including funnel conversion rates, cohort retention, and behavioral trends. |
| 4 | [Superstore Data Visualization (Tableau)](Sprint_4_Superstore_Tableau/README.md) | Built interactive dashboards in Tableau to present KPIs, user behavior, and business performance with a focus on clarity, UX, and analytical storytelling. |
| 5 | [Superstore Storytelling with Data](Sprint_5_Storytelling_Tableau/README.md) | Explained root causes of high return rates and presented actions through a Tableau Story and monitoring dashboard. |
| 6 | [Shopify App Analysis (Power BI)](Sprint_6_Shopify_PowerBI/README.md) | Designed and developed interactive Power BI dashboards integrating multiple data sources to analyze app performance, reviews, and developer responsiveness. |
| 7 | [Final Project – Zomato Performance Analysis](Sprint_7_Final_Project_Zomato/README.md) | Evaluated restaurant and cuisine sales performance using Excel and Tableau; built dashboards and delivered recommendations to improve revenue through partnerships, cuisine focus, ratings, and metro strategies. |

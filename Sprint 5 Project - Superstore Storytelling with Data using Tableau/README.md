# Sprint 5 – Superstore Storytelling with Data (Tableau)

## 📌 Objective
Explain root causes of **returned orders** and propose actions via a Tableau Story and dashboard.

## 🛠 Tools & Skills Used
- Tableau (calculated fields, dashboards, stories)
- Excel (`Superstore.xls`)

## 📊 Key Steps
1. Left-joined **Returns** to **Orders**; created a `Returned` calc (`Yes`=1, `Null`=0).
2. Built worksheets: returns vs. sales, return rate by category, by customer (filtered to >1 orders), by state, and over time.
3. Designed a returns monitoring dashboard; created a Story to present findings and actions.

## 📈 Results / Insights
- Identified categories/customers/states with above-average return rates.
- Seasonal patterns in returns and specific drivers highlighted.
